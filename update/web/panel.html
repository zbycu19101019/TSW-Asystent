Telefon / tablet (ta sama sieć Wi-Fi)
…
Zapora Windows blokuje telefon. Program działa, ale połączenia z sieci są zatrzymywane.
Windows zapyta o zgodę administratora. Reguła dotyczy tylko tego programu i tylko sieci prywatnych (domowych).
Aplikacja Android „TSW Ekran” znajduje ten komputer sama (przycisk „Szukaj”). W przeglądarce telefonu wpisz adres powyżej. Przy pierwszym starcie Windows zapyta o zgodę zapory — zaznacz „Sieci prywatne”.
Głosy offline (przygotowanie z góry)
Ok. 1900 stałych komunikatów na głos (20–30 minut, raz, w tle — można jeździć). Potem lektor mówi od razu, a nowe teksty dochodzą w trakcie jazdy.
Sterowanie z telefonu
Kod parowania: ······
Na telefonie: aplikacja TSW Ekran → przesuń palcem w bok → „Sterowanie” → wpisz kod. Kod działa raz.
Telefon wciska klawisze gry (domyślne skróty TSW: A/D nastawnik, ; ' hamulec, Q czuwak, spacja syrena…) tylko wtedy, gdy na pierwszym planie jest okno Train Sim World. Zmiana klawiszy: config.json → "controlKeys".
